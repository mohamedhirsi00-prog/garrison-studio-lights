# The Garrison Studio Lights (phone)

One-tap lighting scenes for The Garrison Studio's Neewer TL60 RGB tubes, from an Android phone, over Bluetooth.

Open **https://mohamedhirsi00-prog.github.io/garrison-studio-lights/** in **Chrome on Android**, then
Chrome menu → **Add to Home screen**.

- Scene buttons fade every tube in 2.5 s; press and hold a scene to edit or delete it; **New scene** makes your own.
- **Music mode** moves the stage tubes with the sound from the phone's microphone.
- Each tube has a name and a job (Stage left, Stage right, Face light, Not used).
- First time on a phone: tap **Connect** on each tube and pick it from the list; the app flashes the tube and asks
  if it was the right one, then remembers it.

Built from the laptop program's settings by `build_phone_app.py` (Neewer TL60 "Infinity" Bluetooth protocol, from the
open-source NeewerLite-Python project).
